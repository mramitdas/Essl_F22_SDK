# Essl F22 SDK Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a synchronous, standard-library-only Python SDK that reads and writes users, attendance, fingerprint metadata, access timezones, and performs non-destructive user access blocking on the validated eSSL/ZKTeco F22 terminal.

**Architecture:** A small protocol layer encodes ZKTeco TCP frames and a session layer handles connect/auth/large buffered reads. A device layer maps commands to typed models. A block manager assigns a reserved deny-all timezone to a user, persists the original timezone assignment in SQLite, and restores it on unblock. The user record and fingerprint templates are never modified for blocking.

**Tech Stack:** Python 3.12+, standard library (`socket`, `struct`, `sqlite3`, `datetime`, `pathlib`), pytest, ruff, mypy.

**Spec:** `docs/superpowers/specs/2026-10-24-essl-f22-sdk.md`

## Global Constraints

- Target Python `>=3.12`; ruff target `py312`.
- Runtime dependencies: standard library only.
- Transport: TCP only, default port `4370`.
- Do not modify or delete fingerprint templates or user records when blocking.
- Do not rely on the `E0` enable bit; this firmware ignores it for access.
- Block by assigning a deny-all access timezone.
- Persist original user timezones in SQLite keyed by device serial number and `uid`.
- Unit tests must not require hardware.
- Hardware tests are marked `hardware` and skipped unless `ESSL_F22_HOST` is set.
- Run verification with `uv run pytest`, `uv run ruff check .`, and `uv run mypy src/`.
- Commit only when the human partner has explicitly approved commits.

## Review Focus

- Truncated or malformed user, attendance, fingerprint, timezone, group, or
  user-timezone blobs must raise `ProtocolError`, never `struct.error`,
  `IndexError`, or `KeyError`. Tests belong to Tasks 5, 6, and 7.
- Large attendance reads must span multiple chunks, return the complete
  payload, and always send `CMD_FREE_DATA`. Tests belong to Tasks 4 and 9.
- A socket timeout or reset during a command must close the transport and
  raise `DeviceTimeoutError` or `DeviceConnectionError`, never hang. Test
  belongs to Task 3.
- Unblocking with missing or stale local state must fall back to the group
  timezone, return `state_found=False`, and never write another user's
  assignment. Test belongs to Task 12.
- Timezone-slot discovery must never overwrite a slot referenced by a group
  or a non-blocked user; it must raise `NoFreeTimeZoneSlotError` when none is
  free. Tests belong to Task 12.

def _buffer_size(data: bytes) -> int:

Read the `<I` total size at `0`. If `record_count == 0`, return `[]`. If
`total_size == 0`, return `[]`. If `total_size % record_count != 0`, raise
`ProtocolError`. Only `record_size == 40` is supported; raise
`ProtocolError` for other sizes. For each 40-byte record, strip the
optional 9-byte prefix `b"\xff255\x00\x00\x00\x00\x00"` if present at the

timestamp with:

```python
def decode_attendance_timestamp(raw: bytes) -> datetime:
    value = int.from_bytes(raw, "little")
    second = value % 60
    value //= 60
    minute = value % 60
    value //= 60
    hour = value % 24
    value //= 24
    day = value % 31 + 1
    value //= 31
    month = value % 12 + 1
    value //= 12
    year = value + 2000
    return datetime(year, month, day, hour, minute, second)
```

`TimeZone.from_response` expects exactly 32 bytes: `<H` slot at `0`, seven
