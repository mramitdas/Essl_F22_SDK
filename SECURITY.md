# Security Policy

## Supported versions

Only the latest released version of the Essl F22 SDK receives security updates.

## Reporting a vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Report privately to [mramitdas99@gmail.com](mailto:mramitdas99@gmail.com)
with a description of the issue, steps to reproduce, and affected versions.
You will receive an acknowledgement within 72 hours and a fix timeline update
within 7 days.
